# Read Me

## Summative Assessment: Java Language Fundamentals Storage Lockers

### Introduction

Lockdown Inc. has hired you to code the prototype for a storage locker access solution.

This product will be used specifically at comedy shows to securely store attendees' cell phones.

The user of this product isn't the comedy show attendee, though. Instead, it's a guest services representative who will accept the attendees' phones and secure them into lockers. The representative will provide attendees with a PIN. Presenting this PIN will allow attendees to gain access to use their phones during the show.

Once the show is complete or if someone decides to leave early, the locker can be opened and released, available for another attendee.

Another team has designed the prototype of this product. You are presented with a user story, a flow chart of the application, and the text for the main menu.

Lockdown Inc. is super excited to see this prototype come to life as they have big plans for how it might expand in the future. The basic functionality must be, pardon the pun, **locked down** tight before moving on.

The prototype will be tested by a QA team who have a specific set of requirements for acceptance of the prototype.
